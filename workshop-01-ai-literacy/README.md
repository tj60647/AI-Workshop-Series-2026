# Workshop 1: AI Literacy — How It Actually Works

**Duration:** 3 hours
**Format:** Part lecture and live demo, part hands-on experimentation

---

## Overview

These systems predict language. In this hands-on workshop, we'll look at what that means in practice: how models sample and generate text, how settings shape the output, and why the same prompt behaves differently across different models.

You'll work in a sandbox, testing models side by side, writing instructions, and exploring how knowledge bases let you ground AI in your own content. Along the way, we'll start naming the design surfaces that shape what you're seeing — instructions, parameters, knowledge, and tools — because these aren't just technical details; they're where authorship lives.

The first half is short talks and live demos; the second half is all about doing, experimenting, observing variation, and building a practical feel for how these tools behave and where they break.

**No technical background required.**

---

## Learning Goals

- Understand how language models generate text (sampling, temperature, probability)
- Recognize how prompt phrasing and model settings affect output
- Compare behavior across different models side by side
- Begin naming the four design surfaces: **instructions**, **parameters**, **knowledge**, **tools**
- Experience grounding AI responses with a knowledge base
