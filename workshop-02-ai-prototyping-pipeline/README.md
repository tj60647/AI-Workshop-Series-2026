# Workshop 2: AI Prototyping Pipeline — From Prompt to Production

**Duration:** 3 hours
**Format:** Part demonstration and guided setup, part hands-on building

---

## Overview

This is the plate tectonics workshop — the ground is moving and it moves fast.

We'll walk through a full prototyping pipeline — from AI Studio to GitHub to Vercel — and you'll ship a working project in a single session. Along the way, we'll cover how to connect your own content through Google Drive, how to write better prompts using structured vocabulary and glossaries, and how vibecoding actually works in practice.

The tools are accessible, the results are real, and the gaps are instructive. The first half is demonstration and guided setup; the second half is hands-on building, comparing approaches, and starting to evaluate what your prototypes actually do.

**Some comfort with web tools is helpful but not required.**

---

## Learning Goals

- Walk through the full pipeline: AI Studio → GitHub → Vercel
- Ship a working prototype in a single session
- Connect personal content via Google Drive
- Write stronger prompts using structured vocabulary and glossaries
- Understand what "vibecoding" means in practice and where it breaks
- Begin evaluating what your prototype actually does
